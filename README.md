# Kibbit para Mac

Kibbit es una criaturita de pixeles que vive en una esquina de tu escritorio: duerme en su cuarto, sale cuando lo llamas, te ayuda con lo que necesites y te avisa de tus pendientes.

**Descárgalo en [kibbit.app](https://kibbit.app).**

Aquí se publican los instaladores de cada versión (`Kibbit.dmg`), firmados con Developer ID y notarizados por Apple. Kibbit se actualiza solo: no necesitas venir aquí.

Requiere macOS 13 o más nuevo.
